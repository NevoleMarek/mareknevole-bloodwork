Extract all blood test results from this medical PDF report.

Return ONLY a raw JSON object — no markdown, no explanation, no code fences.

The JSON must match this exact structure:

{
  "date": "YYYY-MM-DD",
  "measurements": [
    {
      "label": "Test Name As Written",
      "value": 98.0,
      "unit": "mg/dL",
      "referenceRangeMin": 70.0,
      "referenceRangeMax": 100.0,
      "status": "normal"
    }
  ]
}

Rules:
- "date": the specimen collection date from the report; if not found, use today's date in YYYY-MM-DD format
- "label": exact test name as it appears in the report
- "value": numeric value only (no units)
- "unit": unit string as written in the report
- "referenceRangeMin" / "referenceRangeMax": numeric bounds from the reference range; null if not provided
- "status": one of "normal", "borderline", "high", "low" — infer from the report's flagging or the reference range
- Include every individual test result; do not omit any
